# YOLOv11 Cat Dog Breed Identification System

## Body

YOLOv11 Cat and Dog Breed Identification System Based on Deep Learning YOLOv11: A Cat and Dog Breed Identification Detection System (YOLOv11+YOLO dataset + UI interface + login registration interface + Python project source code + model)

This paper proposes a cat and dog breed identification detection system based on deep learning YOLOv11, which can efficiently and accurately identify 37 cat and dog breeds. By constructing a dataset containing 13,983 images (training set 12,879, validation set 736, test set 368), combined with the YOLOv11 object detection algorithm, it achieves real-time detection and classification of multiple breeds of cats and dogs in complex scenarios. The system is developed using Python, integrating a user-friendly UI interface and supporting login registration functions. Experimental results show that the system achieves high recognition accuracy and robustness on the test set, providing technical support for pet management and intelligent security applications.

✅ User Login Registration: Supports password verification and security validation.
✅ Three detection modes: Based on the YOLOv11 model, supports image, video, and real-time camera detection, accurately recognizing targets.
✅ Dual-screen comparison: Displays the original scene and detection results simultaneously on the screen.
✅ Data visualization: Real-time table displaying the category, confidence, and coordinates of detected targets.
✅ Intelligent parameter adjustment: Offers a confidence slide bar to dynamically optimize detection accuracy, adapting to different scene requirements.
✅ Sci-fi style interactive interface: Dark theme paired with dynamic light effects, reducing visual fatigue and enhancing operational experience.
